## Intiution behind K closest elements using Binary-Search

Please understand following then go to the solution. The binary search can be used to find a window of size k in the sorted array that is closest to the target value x as well. The idea is to use binary search to find the left boundary of the window, and then return the k elements starting from that boundary.
